# React Bits components

Copied unchanged (apart from dropping the `'use client'` line, which Vite doesn't need) from
[DavidHDev/react-bits](https://github.com/DavidHDev/react-bits), `src/ts-default/`, on Oct 18:

| Component | Used for |
|---|---|
| `SplitText` | Scene headings on the story page rise in word by word (GSAP SplitText) |
| `ShinyText` | "Scroll to explore" cues and the "Open live dashboard" sign |
| `Magnet` | The nav's "Open dashboard" button and the dashboard sign pull toward the pointer |
| `CountUp` | The task card's 0:60 → 0:42 countdown on the story page; done counts in the Staff drawer |
| `ClickSpark` | Sparks on Send Task and Reroute in the dashboard |
